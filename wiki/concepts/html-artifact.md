# HTML artifact

HTML artifact 指 Agent 为一个具体任务临时生成的 HTML 工作界面，而不是长期维护的正式网页。它通常服务于一次阅读、比较、调参、审阅、导出或回流。

典型形态包括 PR 解说页面、配置编辑器、prompt 调参面板、研究报告、方案比选网格、设计原型和事故复盘页面。它的价值不在于成为最终事实源，而在于把复杂上下文渲染成人类愿意读、愿意操作、能导出结果的界面。

## 边界

HTML artifact 不等于 source of truth。长期可追溯的事实仍应留在 Markdown、YAML、JSON、代码或数据库里。HTML 更适合做 rendered interface。
