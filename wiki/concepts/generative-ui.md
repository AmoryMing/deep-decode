## 定义

让 AI 模型直接产出最终用户看到的界面像素或结构，绕开"工程师写代码 → 浏览器渲染"这条传统管线。

## 三种实现路径（颗粒度从粗到细）

1. **AI 填模板**（Gamma / Tome）：模板和 HTML 仍然是人类工程师写的，AI 只填字、选图、调色。渲染层不变。
2. **AI 写 HTML**（Websim / v0 / 早期 generative UI 论文）：AI 实时生成 HTML/CSS/JS，浏览器照常渲染。代码是变量，渲染层不变。
3. **AI 出像素**（flipbook.page）：跳过 HTML 直接生成像素流。浏览器渲染层被替换成视频扩散模型。

## 命题

第 3 条路径是当下最激进的赌注：**HTML/CSS/JS 这条三十年的管线第一次出现可信的"被替换"原型。**

## 反对论据

- 无 SEO（搜索引擎索引不到像素里的文字）
- 无可访问性（屏幕阅读器看到的是空白）
- 无可交互（无法 copy/paste、无法表单提交、无法跳转外链）
- 幻觉极隐蔽（视觉媒介的视觉自信掩盖事实错误）

## 适用场景判断

| 场景 | 是否会被吃 | 理由 |
|---|---|---|
| 百科信息浏览 | 会 | 信息密度低，结构灵活，幻觉容忍度高 |
| 教育/儿童读物 | 会 | 视觉化是核心价值，结构次要 |
| 企业 SaaS 应用 | 部分 | 仪表盘可能，但表单/审批流不行 |
| 金融/医疗/法律 | 不会 | 审计追溯需要确定性结构和文本日志 |
| 编码 IDE | Shah 押注会，作者怀疑 | 需要精确的字符位置，模型今天做不到 |
