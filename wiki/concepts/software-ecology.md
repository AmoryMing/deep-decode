# Software Ecology / 软件生态学

> 由 Adam Bender（Google）在 I/O 2026 演讲中明确定义的研究框架。

## 定义

> Software ecology is the holistic study of the socio-technical ecosystems that produce software.
> （软件生态学，就是把生产软件的 socio-technical ecosystem 当成一个整体来研究。）

## 关键点

- ecosystem ≠ system：ecosystem 是 dynamic network of interdependent actors that co-evolve with environment
- developer ecosystem 是 socio-technical 的，**人 + 技术不可分**——技术架构、流程、组织结构、工程文化都是同一系统的不同维度
- emergent property（涌现属性）只能从整体看到——单看某个工具看不出来
