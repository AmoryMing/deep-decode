# B2B 调头 — Anthropic 第一次超过 OpenAI 的那一票

## 主判断

Ramp 5 月 AI Index 显示 Anthropic 在 B2B 采用率上 34.4% 首次反超 OpenAI 的 32.3%。这不是单一发布事件，是企业市场的曲线第一次交叉——同时段 Anthropic 估值谈到 9000 亿筹 300 亿，ARR 从 90 亿冲到 440 亿，企业贡献超过 80%。卖工作流的赢了卖 API 的。

## 核心数据

- Ramp 5/2026 AI Index: Anthropic 34.4% / OpenAI 32.3%
- 当月变化: Anthropic +3.8pp / OpenAI -2.9pp
- 年同比: Anthropic 9% → 34.4%（约 4 倍）; OpenAI 大致持平略降 1pp
- 样本: Ramp 平台上 5 万家以上公司，美国为主
- 引用人物: Ara Kharazian（Ramp 经济学家）

## 反判断 / 盲区

1. Ramp 只测"付费公司家数"，不测使用量 / 单位 token 价值。可能一家 Fortune 500 给 OpenAI 一年烧 5000 万比 1000 家 startup 给 Anthropic 一年付 100 美元/家更值钱
2. 美国偏向严重——全球数据未必这样
3. VentureBeat 指出三个削弱因素：成本（昂贵模型逼用户找替代）、质量（Claude 近期 outage 与质量下降的公开抱怨）、定价（Opus 4.7 图片处理成本三倍）
