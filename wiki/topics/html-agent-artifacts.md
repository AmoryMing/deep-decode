# HTML artifacts：Agent 输出从文档转向工作界面

## 角度

这不是 HTML 替代 Markdown 的格式党争，而是 Agent 输出的角色变化：当人类越来越少直接手改 Agent 输出，Markdown 的“易编辑”优势变弱；HTML 的可视化、交互、分享和回流能力变成协作优势。

核心判断：Markdown 退回 source / 草稿 / 日志 / 契约层；HTML artifact 走到前台，成为人类审阅、操作和反馈 Agent 的工作界面。
