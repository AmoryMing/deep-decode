## 核心事实

发布时间：2026-04-28
联盟规模：9 个 connector，一次性发布
合作方表述（Anthropic 官方原话）：

> "Today, with a coalition of partners including Blender, Autodesk, Adobe, Ableton, and Splice, we're releasing a set of connectors—tools that let Claude work alongside the software creative professionals rely on, so creatives can extend their reach."

## 9 个 connector 逐个

| 工具 | Claude 能做什么 | 工具属性 |
|------|----------------|----------|
| Adobe for Creativity | 自然语言编排 50+ Creative Cloud 工具（Photoshop/Premiere/Lightroom/Illustrator/Firefly/Express/InDesign/Adobe Stock）多步工作流 | 订阅制商业软件 |
| Ableton Live + Push | 答案锚定在 Live/Push 官方文档；不写工程，做"懂 Live 的客服" | 商业 DAW |
| Splice | 在 Claude 内搜索免版权采样库 | 订阅采样库 |
| Affinity by Canva | 自动化批量生产任务（图像批改、图层重命名、批量导出）、在应用内生成自定义功能 | 永久授权创意三件套 |
| Autodesk Fusion | 对话生成/修改 3D 模型（需 Fusion 订阅） | CAD/工业设计 |
| Blender | 自然语言访问 Python API；分析/调试场景；批量改属性 | 开源 3D 套件 |
| SketchUp | 把对话当 3D 建模起点（房间、家具、场地概念），导入 SketchUp 精修 | 3D 建模 |
| Resolume Arena | 自然语言实时控制 Arena | VJ/现场视觉 |
| Resolume Wire | 自然语言控制 Wire | VJ 节点编辑 |

## 价格/可用性

Anthropic 官方未在公告中披露分级：哪些计划（Free/Pro/Max/Team/Enterprise）可用。
9to5Mac 表述："available immediately across every Claude plan, including Free"——但这一说法需要二次核实，官方公告原文未明示。

## 战略读法

这不是单点功能，是 connector 矩阵的"垂直突破"：从生产力工具（Notion/Slack/GitHub/Google）跨入专业创意工具栈。
关键缺位：Figma 没接入。Figma 自己就是 MCP host（Figma MCP server 已上线），属于平行竞争而非合作。

## 写作角度

- 卡位论：Anthropic 用 connector 矩阵定义"AI 助手 + 专业工具"标准接口，比单点 Copilot 更具系统性
- MCP 生态信号论：connector 是 MCP 的封装态，9 个一次性放出，等于给 MCP 协议做了一场盛大背书
- 创作工具的护城河重估：Adobe/Autodesk 等护城河被"自然语言外壳"重新定价
