## 核心事实

- 加入级别：**Corporate Patron**（公开档位的最高级之一，门槛 €240,000/年）
- 年度承诺：**€240,000**（约 $281,000），可覆盖 4 名全职 Blender 开发者年薪
- 资金用途：Blender 核心开发，包括维护和持续改进 Python API 等基础能力——也就是 Claude Blender connector 调用的同一个 API
- 同时关系：Anthropic 同步发布 Claude Blender connector，本质上是"既出钱又消费"

## Blender CEO Francesco Siddi 的公开表态

> "This is towards helping Blender itself as a software, this is not an AI takeover."
> "In these uncertain and divisive times, we appreciate Anthropic offering support to the Blender project in a Patron-level membership."
> Siddi 强调赞助"no strings attached"，与 Meta 的赞助同性质，不代表 Blender 认可 Anthropic 的产品或使命。

## 社区反应

部分艺术家在 BlenderNation/Reddit 称这笔钱为"bloody money"，对生成式 AI 公司参与 Blender 资金生态持保留态度。但 Blender 历史上接受 Meta、Microsoft、AMD、NVIDIA、Intel 等大厂赞助，本次质疑没有形成主流意见。

## 战略读法

- Anthropic 此举把"消费开源"和"反哺开源"绑成一对：靠 Blender Python API 卖 connector，同时为 API 续命
- 对比 OpenAI/Google：未见 OpenAI 参与 Blender 基金的公开记录。这是一次 PR 上的差异化卡位
- €240k/年对 Anthropic 微不足道（一轮 IPO 前融资的 0.0x%），但对 Blender 是"4 个工程师一年"——最大化杠杆

## 写作角度

- 钱从 Adobe 用户口袋绕到 Blender 工程师工资单——这是一笔生态转移支付
- Anthropic 的"既出钱又调用"姿态，是 OpenAI 至今没干的事
