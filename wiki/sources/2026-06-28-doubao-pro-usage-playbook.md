## 核心论点

豆包专业版 2026-06-24 上线，三档定价 68/200/500 元/月。真正的分水岭不是模型变强，而是新增的「办公任务模式」——豆包第一个 Agent 版本，能操作本地电脑、跑浏览器、调用 Office/飞书、调 Skills、设定时任务。

全网实测交叉验证出一条铁律：**它在结构化、能在浏览器里搞定的活儿上接近交付级，一碰本地客户端操作、需要精确事实、需要长程编程就掉链子。** 最锋利的证据是 36kr 同一家媒体三篇口径相反的实测——一篇标题《对标 Claude Opus 4.6》、一篇《327 张图 3 分钟归档》、一篇《4 个办公任务 3 个没干成》。差别不在豆包好不好，在任务落在哪半边。

## 关键事实（带出处）

- 上线时间 2026-06-24；定价标准 68/加强 200/高级 500 元/月，包年 688/2048/5088 元，学生标准版 38 元/月。额度倍数：标准版为免费版 5 倍以上、加强版为标准 4 倍、高级版为标准 10 倍。[新浪财经](https://finance.sina.com.cn/tech/shenji/2026-06-24/doc-inienieh3128975.shtml)
- 专业版搭载豆包 2.1 Pro，免费版搭载 2.1 Turbo，免费版基础功能与原额度不变。[南方+](https://static.nfnews.com/content/202606/24/c12559995.html)
- 办公任务模式 = 操作本地电脑 + 浏览器 + Skills + 定时任务 + 内置 Office/飞书 + 生成应用/网站。[新浪财经](https://finance.sina.com.cn/jjxw/2026-06-24/doc-inienpmx8304948.shtml)
- 正面实测（36kr）：327 张图约 3 分钟按「年份-月份」二级归档；财报分析交付飞书双表+约 500 字摘要（英伟达 FY2027 Q1 营收 816 亿美元、毛利率 74.9%）；定时财经日报准时稳定。[36kr](https://36kr.com/p/3868483485160710)
- 反面实测（36kr）：4 个动手类任务 3 个没干成（清 C 盘越清越少 3GB→2.82GB、操作飞书表格因只能走 API 找不到本地文件、写直播录制工具因 iframe 授权卡住），唯一成功的是纯浏览器抓小红书评论；对比 Codex 全部可用。[36kr](https://36kr.com/p/3867006268750725)
- 幻觉硬伤（澎湃）：把文心一言、千问归入收费阵营并编造价格；数据可视化首轮多处偏差需人工兜底。[澎湃](https://m.thepaper.cn/newsDetail_forward_33445895)
- 豆包 2.1 Pro（6-23 FORCE 发布）Terminal Bench 2.1 得 71.0（Claude Opus 4.7 为 71.7）；但长程程序合成 ProgramBench 仍差 GPT-5.5 一代。[网易](https://www.163.com/dy/article/L09HGPBC05568RDC.html) / [51CTO 审计](https://blog.51cto.com/u_17459294/14714345)
- API 定价：输入 6 元、输出 30 元、缓存命中 1.2 元/百万 Token；日均调用 180 万亿 Token，火山引擎 MaaS 市占 49.5%。[腾讯新闻](https://news.qq.com/rain/a/20260623A059L400)
- 价格竞争力：对比 Kimi/MiniMax/智谱 49 元入门会员，68 元并不便宜。[每经](https://www.nbd.com.cn/articles/2026-06-25/4436981.html)
- 噱头辨析：豆包做小红书的 P 图/Seedream 5.0 生图/Seedance 2.0 视频/数字分身，多为免费版手机端 AI 创作能力，非专业版独占。[网易](https://www.163.com/dy/article/KQPJRTAM05169CIL.html)

## 金句（英文附译）
