# Claude Code v2.1.139 release

## 一手出处

- [Claude Code v2.1.139 GitHub release](https://github.com/anthropics/claude-code/releases/tag/v2.1.139)
- [Agent View docs](https://code.claude.com/docs/en/agent-view)
- [/goal docs](https://code.claude.com/docs/en/goal)

## 核心事实

- 版本 `v2.1.139` 发布于 2026-05-11 18:43:42 UTC。
- 新增 `agent view` Research Preview，通过 `claude agents` 打开，用于查看 running、blocked on you、done 的 Claude Code sessions。
- 新增 `/goal` 命令，用户设置完成条件后，Claude 可跨 turns 继续推进，并显示 elapsed / turns / tokens overlay。
- 插件、hooks、MCP、OTEL 和终端 UI 都有多项改动：`claude plugin details`、hook `args: string[]`、`PostToolUse.continueOnBlock`、`CLAUDE_PROJECT_DIR`、subagent tracing headers 等。

## 角度

这次 release 的主线是任务编排。`agent view` 解决多个 session 的横向管理，`/goal` 解决单个任务跨轮次推进。Claude Code 的产品重心正在从“更好的对话”移向“更好的工作组织”。
