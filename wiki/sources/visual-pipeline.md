# 图文规范

## 核心宗旨

**图要反映读者的认知逻辑，不是文章的信息摘要。** 一张图发到群里，不看正文也能 get 核心概念。

## 图在文章中的角色

标杆文章（"脑手分离"）有 5 张图，每张对应一个章节的核心概念：
- 00_系列封面 -- 品牌识别
- 01_耦合vs解耦架构 -- 第一个核心概念
- 02_四层认知基建 -- 第二个核心概念
- 03_安全隔离设计 -- 第三个核心概念
- 04_上下文工程 -- 第四个核心概念
- 05_竞品战场态势 -- 战场全景

**文章正文用 `![描述](图片路径)` 嵌入图片。** 图和文字穿插，不是堆在一起。

## 每篇文章的图清单

1. `00_系列封面.svg` -- 每篇必有
2. 正文每个主要章节一张概念图 -- 命名 `01_概念名.svg`、`02_概念名.svg`...
3. 总图数 = 章节数 + 1（封面），一般 4-8 张

## SVG → PNG 流程

```
写 SVG → cairosvg.svg2png(scale=2) → PNG（高清） → 嵌入文章和 docx
```

## 设计规范摘要

**两种风格，按内容选**：
- **概念漫画图**（风格A）：图形隐喻、对比、因果。手绘线条感，可有简笔角色
- **结构化图形**（风格B/Notion式）：流程图、架构图、数据对比。直线、圆角矩形、充分留白

**配色（Notion 日间主题）**：
- 背景 #FFFFFF、正文 #37352F、强调蓝 #2383E2、边框 #E3E2E0
- 警告红 #EB5757、成功绿 #4DB6AC、注意黄 #FFB020、特殊紫 #9B51E0

**字体**：`font-family="PingFang SC, Inter, sans-serif"` -- 中文在前！否则 cairosvg 渲染方框

**尺寸**：宽 800，高 400-620，标题 20-24，正文 14-16，注释 12

**认知排列**：
- 总→分→总（顶部标题→中间子块→底部总结）
- 因→果（左→右或上→下，箭头引导视线）
- 对比（左右并列，差异高亮）

## 避坑（血泪教训）

1. 中文字体必须在英文前：`PingFang SC, Inter` 不是 `Inter, PingFang SC`
2. `✕✓√☑` 渲染为方框，用文字替代。`→` 安全
3. SVG 转 PNG 必须 `scale=2`，否则模糊
4. 中文字符宽度 ≈ 英文 x 1.5-2，rect 宽度要留 20px 余量
5. 不嵌套 foreignObject（cairosvg 不支持）
6. 图文穿插，不要连续放两张图
