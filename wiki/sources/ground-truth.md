# 内容生产系统总纲

来源：`raw/content-production-bundle/vault/.../ground-truth.md`（2026-04-15 定稿）

这是前代系统的"宪法"——所有其他文件实现它定义的规范。与其他文件冲突时，以此为准。

## 系统架构

信源 → 选题 → 写作 → 可视化 → 分发 → 反馈循环

六个环节，每个环节有独立规范和工具。

## 信源体系（三层）

1. **一级信源**：官方工程博客、论文、源码（最高可信度）
2. **二级信源**：行业分析师、知名技术博客（需交叉验证）
3. **三级信源**：社交媒体、Reddit/HN 讨论（只做线索，不做证据）

## 信号评分框架

5 个维度，每维度 1-3 分，满分 15：

| 维度 | 说明 |
|------|------|
| 时效性 | 24h 内 = 3，一周内 = 2，更旧 = 1 |
| 信源权威 | 官方 = 3，行业 = 2，社交 = 1 |
| 独特性 | 首次揭示 = 3，新角度 = 2，跟进 = 1 |
| 影响面 | 全行业 = 3，一个领域 = 2，小众 = 1 |
| 可写性 | 素材丰富 = 3，够用 = 2，单薄 = 1 |

- 10+ 分 → 深度叙事（3000-5000 字）
- 6-9 分 → 标准分析
- 3-5 分 → 快讯
- <3 分 → 不写

## 三种内容类型

| 类型 | 定位 | 字数 | 对应模板 |
|------|------|------|---------|
| decode | 深度拆解 | 2000-4000 | templates/decode.md |
| brief | 情报日报 | 短摘要+评分 | templates/brief.md |
| practice | 实操手册 | 步骤+截图+避坑 | templates/practice.md |

## 企媒风格适配

文章面向企业内部分发时的特殊规则：
- 读起来是纯行业研究，不是提案或建议
- 三种嵌入策略：结构嵌入（把想推的事放在"行业趋势"里）、强调嵌入（对齐业务的部分多展开）、对比嵌入（竞品分析里自然带出方向）
- 绝对不能写成"建议公司应该..."

## AI 味检查清单

禁用词/句式及替代：

| 禁用 | 替代 |
|------|------|
| "值得注意的是" | 直接说 |
| "让我们" | 删掉 |
| "在X篇文章中" | 不暴露语料库 |
| "信源显示" | 具体说谁说的 |
| "分析者XXX" | 直接叫名字 |
| 自封"原创概念" | 直接用，不宣布 |

## 与当前 content-factory 的关系

content-factory 是 ground-truth 的"第二代实现"——保留了核心理念（评论员定位、三层信源、图文穿插），但简化了架构：
- 去掉了信号评分（改为人工判断）
- 去掉了自动分发管线（改为手动+脚本辅助）
- 去掉了播客管线
- 保留了写作规范和概念图设计规范
- 新增了 wiki 知识库体系（ground-truth 没有）
