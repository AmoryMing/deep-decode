## 核心论点

Config 2026（2026-06-23 至 25，旧金山 Moscone）一口气发了六样：Code Layers、Figma Motion、shader 填充与效果、生成式插件、画布上的 Weave 图像工具、带技能（skills）与连接器（connectors）的更新版 Figma agent。它们共享一个主张——代码、动效、shader、AI 工具都该活在 Figma 画布上，和组件、团队并排，而不是散在十几个独立工具里。Dylan Field 的定调："代码不是设计的对立面，代码是设计的材料。"对设计师，这把单向的 design-to-code 交接换成了双向的 design-with-code，把角色从'工具的使用者'推向'工具的搭建者'。

## 关键事实（带出处）

- 时间地点：2026-06-23~25 旧金山 Moscone；开幕 keynote 6-24 9:00-10:20 PDT，Dylan Field 主讲。[agenda]
- 六大发布：Code Layers / Figma Motion / shader 填充与效果 / 生成式插件 / Weave 工具 / 更新版 agent（skills + connectors）。[help center]
- Code Layers：一键或一句话把设计图层转成可交互代码图层，可并排比较多个代码方向，可再抽回成可编辑设计，和 GitHub 双向同步；closed beta，2026 年 7 月起放量。[figma blog]
- Figma Motion：时间轴关键帧动效进设计文件，动画跨组件传递，Dev Mode 显示时间轴与缓动值，导出 CSS/JSON/React/MP4/WebM/Animated SVG/GIF，兼容 MCP；6-24 起 open beta，所有套餐 Full seat，agent 可生成首版关键帧（beta 免费）。[help center]
- Shader：自然语言或参考图描述，agent 生成 WebGPU 效果，参数化可调可叠；仅付费套餐 Full seat，教育/政府/Starter 不可用，GA 后耗 AI 积分。[help center]
- 生成式插件：用一句话造出文件内可复用插件（重排图层、统一间距、查找替换），Figma 托管运行；付费套餐 Full seat。[help center]
- Weave：节点式 AI 图像工作流进画布（替换背景、加 logo、风格迁移），限 Pro/Org/Enterprise，beta 免费；Community 上的 Weave 工作流已 GA。[help center]
- agent：可建自定义技能、搜网、MCP 连接器（Notion/Slack/GitHub/Atlassian/Granola/Hex）、附文件；对话默认对团队可见（6-23 起），将扩到 FigJam/Slides。[figma blog]
- 公开缺口：AI 积分 GA 定价未公布；agent 底层模型未披露；Code Layers GA 时间表未给。[explainx]

## 金句（英文附译）

- "Code is not the opposite of design. Code is material for design." —— 代码不是设计的对立面，代码是设计的材料。（Dylan Field）
- "No tool should limit where an idea can go." —— 工具不该限制一个想法能走多远。（Dylan Field / Figma blog）
- "AI has lowered the floor... Designers, creatives, builders: You will raise the ceiling." —— AI 把门槛拉低了，天花板要靠你们抬高。（Dylan Field）
- "AI is no longer a feature, but a part of the canvas." —— AI 不再是一个功能，而是画布的一部分。（Mercari 设计师现场报告）
- "less 'replacing Adobe' and more absorbing the reasons you'd switch between tools" —— 与其说取代 Adobe，不如说把你切换工具的理由都吞了进来。（设计师 Blossom Agard）

## 可写角度

- 主线（采用）：站在设计师立场——Config 2026 把"设计工具"往"AI 创作平台"推了多远，对一线设计工作意味着什么。核心张力：当造工具变得和用工具一样容易、动效和代码都进同一文件，设计师的不可替代价值落在判断力上（"抬高天花板"）。
- 反面：免费 beta 是钓鱼期，付费墙 + 未公布的 AI 积分定价 + 把六种活儿压给一个设计师，可能是能力放大也可能是岗位压缩。
- 竞争：Code Layers vs Cursor/Lovable，Motion vs After Effects，Weave vs Midjourney，整体 vs Adobe——不是"杀死 Adobe"，是"吞掉切换理由"。
