# Developer Diary Index

Developer diary 记录抽象的业务实践、方法论和判断，不记录流水账式的工程动作。

它和 changelog 分开：

- **Changelog**：今天具体改了什么、生成了什么、验证了什么。
- **Developer Diary**：这个动作背后的业务问题、抽象方法、跨行业借鉴和可复用经验。

分开本身也是一条实践：同一段开发经历有两种价值。一种是可追溯，另一种是可传播。前者进 changelog，后者进 developer diary。
