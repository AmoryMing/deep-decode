# 设计这件事，正在被切成三段

## 摘要

5 天发生 3 件事的合并解读：4/17 Anthropic 发布 Claude Design（设计稿直接出代码 + Implementation Bundle 一键交给 Claude Code），4/21 OpenAI 发布 gpt-image-2（reasoning 嵌入图像生成，付费层叫 Thinking Mode），中间 4/16 Anthropic CPO Mike Krieger 辞去 Figma 董事席位。核心论点：AI 切的不是整个设计师职业，是中段执行——把"判断段（这值不值得做）+ 执行段（怎么做出来）+ 收尾段（拧成品牌一致）"切成三层后，AI 这一刀精准落在中间。Figma 当天跌 7%、YTD 跌 35%，Canva 选择融入生态，Google Stitch 在赛道里抢位。Fanny @ Design Bootcamp 的设计师视角是冷静标尺：流水线优化吞吐量，但设计不总是吞吐量问题；被压缩掉的"两像素反复调"是创意摩擦，是价值不是浪费。

## 写作特点

- **多源合并解读（meta-decode）**：3 个事件 + 1 篇设计师亲历 + 市场反应数据。模式不是"逐篇拆"，是"把同一周的多个动作合起来看出共同方向"——这是行业窗口期的写法
- **概念命名密度**：设计三段分层、意图到像素短链路、Implementation Bundle、创意摩擦、Thinking Mode 定价、Visual Thought Partner——每一个都是可独立传播的标签
- **官方措辞 vs 市场信号的对照**：Anthropic 说"complement Canva not replace"，但 Figma 7% / 35% 的数字直接把外交辞令拆穿——读者不能只看措辞要看资本怎么投票
- **三个身份的落地段**：PM / 设计师 / founder 各得其所的"对你意味着什么"，是企媒风格落地的范本
- **盲区章节**：两个"不会被说破的细节"（Anthropic 不提 Figma、Thinking Mode 把 reasoning 当商品定价）+ Research Preview 的真话——三个反向解读，避免陷入官方叙事
- **设计师自己的话当压舱石**：不是 Anthropic PR 稿当结论，是引用一线设计师 Fanny 的判断断点。"Pipelines optimize for throughput, and design isn't always a throughput problem" 这句话作为全文核心刹车

## 复盘备注

- **写法可复用**：行业窗口期（5 天 3 件事）这种"密集动作合并解读"是一类可复刻的选题模式，应建模成单独的写作模板
- **数据点的强度**：Figma 7% 当日跌 + 35% YTD + CPO 辞董事时间点，三个独立证据收敛到同一结论。这种"用市场行为而非声明做证据"的写法应在 voice.md 里固化
- **Research Preview 这个标签的解读价值**：官方不会说的话，标签本身已经在说。这个观察方法可推广到其他产品发布拆解
