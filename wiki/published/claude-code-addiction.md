## 核心论点

从游戏设计原则和 Tesler 定律两个维度解释 Claude Code 的成瘾机制和产品成功：
1. 短反馈循环 + 可变奖赏 + 劳动错觉 = 游戏级成瘾体验
2. Tesler 定律：精致 AI 产品砍功能追求简单，Claude Code 让 AI 吞掉复杂度追求"感知简单"
3. 代码是万物底层接口，AI 移除了人和代码之间的 GUI 层
