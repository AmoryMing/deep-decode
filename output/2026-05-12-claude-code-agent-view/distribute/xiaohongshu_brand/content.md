## 标题

Claude Code 变成任务调度台

## 正文

你打开 Claude Code，看到的不再是一条对话，而是一张状态表：Working、Needs input、Completed。一个屏幕管着好几条后台任务同时跑。更反直觉的是 /goal——它改的不是 prompt，是 turn 和 turn 之间的连接方式，让一条任务自己跑到完成条件满足为止，不用你逐句喂。

这组图讲清楚了一件事：横向并发加纵向续航，人从驾驶员变成调度员，定义任务、设边界、处理阻塞、验收结果。但调度台不等于无人驾驶——evaluator 不独立跑命令也不读文件，权限和成本都没消失。
