嗨，欢迎来到 AI 前沿拆解。这一期讲过去一周 AI 编程工具圈最大的两件事——GPT-5.5 发布，和 Anthropic 把 Claude Code 从 20 美元 Pro 计划悄悄下架。两件事挨在一起发生，中间只隔了不到 60 个小时。战场变了，但变化的不是表面那一层。

先说时间线。4 月 21 号下午，Anthropic 修改 Pro 定价页，Claude Code 的勾选被拿掉。同一小时里，Hacker News 上的截图开始传。两天后，4 月 23 号，OpenAI 发布 GPT-5.5，Codex 团队几乎同步发了一条声明——"Codex 将继续留在免费版和 Plus 20 美元计划里，我们有算力支持"。一头一尾隔了不到 60 个小时。有意思的是，过去 AI 编程工具比的是 benchmark，这一周第一次变成比价格、比留住用户。

先讲第一个发现——GPT-5.5 不是全面碾压 Claude Opus 4.7，而是分叉领先。

怎么理解分叉领先呢。把两家成绩单摊开看，GPT-5.5 在 Terminal-Bench 终端任务上 82.7%，Claude 只有 69.4%。OSWorld 电脑操控，GPT-5.5 是 78.7%，Claude 大约 65%。最夸张的是 MRCR v2 长上下文，GPT-5.5 拿了 74%，Claude 只有 32%。差了 41 个百分点，这不是差距，这是代沟。

但翻到 SWE-bench 代码工程这边，故事就反过来了。SWE-bench Pro 多文件修复，Claude Opus 4.7 是 64.3%，GPT-5.5 只有 58.6%。SWE-bench Verified，Claude 是 87.6%，GPT-5.5 大约 85%。Cursor IDE 的评测里，Claude 也是赢的。

所以不是谁更强，是各自在自己选的赛道上刷新高。GPT-5.5 押注 Agent 类任务——终端、电脑操控、长上下文；Anthropic 押注代码工程——多文件修改、IDE 精度、严谨推理。说到底，两家已经不在同一张考卷上比了。

那这对一线开发者什么意思呢。其实很直接——终端脚本、DevOps 自动化、跨 app 的 GUI 任务，Codex 可能更顺手。但真要改一个多文件的大型代码仓库，Claude Code 仍然是更保险的选择。MindStudio 的对比文里给出了一模一样的路由建议——按任务选工具，比硬选一家更划算。

讲第二个发现——长上下文的差距，会很快改变工程习惯。

刚才那个 MRCR v2 的 41 个百分点差距，听起来像一个数字。但落到实操里，它意味着一件事——把整个代码仓库塞进 prompt、让模型一次看全局的做法，正在从"理论可行"变成"工程首选"。

GPT-5.5 的 API 上下文开到了 1M token，Codex App 里面是 400K。Claude Opus 4.7 没跟上这一步。以前做代码检索怎么做呢？靠 RAG、靠 chunk 精选、靠向量数据库凑上下文。现在至少在 GPT-5.5 这边，"整个项目铺开看"成了一个合理选项。

代价是什么？是 token。GPT-5.5 API 定价 5 美元输入、30 美元输出，比 5.4 翻了一倍。OpenAI 自己的说法是"等效任务消耗 token 更少"。但 Simon Willison 的实测给出了反面证据——他用 xhigh 高推理模式画一张 SVG 鹈鹕骑车图，消耗了 9322 个推理 token 换来好结果；默认模式只花 39 个 token，他的原话是"I've seen better from GPT-5.4"，不如 5.4 好看。

推理 token 消耗差了 239 倍。所以"token 效率提升"这个故事要带着括号读——只有在开启高推理强度时，GPT-5.5 的能力优势才出得来；关着推理用，可能还不如 5.4。

Ethan Mollick 给了一个更准确的描述，叫"锯齿形前沿"。同一个模型，在不同任务上的表现差异悬殊，难以预测。

讲第三件事——Anthropic 这一周，发生了一次流程失控。

4 月 16 号，Claude Opus 4.7 发布。SWE-bench Pro 从 4.6 的 53% 直接跳到 64.3%，涨了 11 个百分点。这是一次结结实实的代码能力升级。一周后 GPT-5.5 发布。间隔恰好压在一起，明显是在抢同一波舆论窗口。

但 Anthropic 在这一周里还干了另一件事——比技术发版影响大得多。

4 月 21 号，Pro 计划的 Claude Code 被悄悄从定价页拿掉。文档从"Pro 或 Max"改成了"仅 Max"。新注册用户要用 Claude Code，必须从 20 美元升到 100 美元或者 200 美元，涨幅 5 到 10 倍。

没有公告，没有邮件。开发者在 Hacker News 上刷到截图才知道的。1 小时内帖子冲上首页。当晚 Anthropic 增长主管 Amol 在 X 上发文解释，他说了三句话。第一句："我们只是在对 2% 的新用户做小规模测试"。第二句："使用模式变化很大，我们现有的计划不是为此设计的"。第三句："每个订阅用户的使用量大幅增加，我们现有的计划架构不是为这种规模设计的"。

拼起来就是一个非常坦白的商业信号——Claude Code 的用户不再按聊天用，按 agent loop 后台长跑用。Opus 4.7 发布后社区里反馈单次会话能跑几个小时，自动化工作流在后台没人盯。按对话次数定价的订阅模型，撑不住这种消耗。

回过头看，Anthropic 2 月刚和 Amazon 签下 250 亿美元算力协议。一边是巨额产能投入，一边是 Pro 订阅承接不了实际使用——这是定价架构和产品形态之间的结构性错配。后来定价页悄悄恢复了，但部分文档变更保留。那位增长主管承诺"下次有变化会先从我们这里听到，不是从 X 截图上"——等于公开承认流程失控。

讲第四件事——OpenAI 的精准反击，时机不像巧合。

Anthropic 改文档的当天，Codex 团队公开发文——"Codex 将在免费版和 Plus 20 美元计划中继续开放。我们有算力和高效模型撑住它"。距离 Anthropic 动作不到 24 小时。两天后，GPT-5.5 发布。

三个动作每一步都踩在对方的软肋上。用户争夺战第一次不是在 benchmark 里打，是在"每月 20 美元能不能用上最好 Agent 工具"这条线上打。

给这条新战线起个名字，叫"20 美元战线"。模型选型的决策权，第一次不在架构师手里，在付账的开发者手里。付 20 美元拿到什么、能用多久、会不会突然被涨价，成了比 SWE-bench 高几个点更决定性的问题。

这条战线背后是两家完全不同的成本结构。NVIDIA 博客披露了一个数字——GB200 NVL72 相比上代，每百万 token 成本降低 35 倍，每兆瓦每秒 token 输出提升 50 倍。Codex 全量跑在这套基础设施上，1 万名 NVIDIA 员工在用。OpenAI 把模型成本压下去之后，还涨了 2 倍定价——说明当前涨价不是在跟 Anthropic 竞价，是在测试市场对更贵模型的支付意愿。

反过来 Anthropic 那 250 亿 Amazon Trainium 协议，产能要今年晚些时候才真正上量。在那之前，Pro 订阅的 Claude Code 用户每多一个，毛利就少一点。"2% 小规模测试"背后，其实是一个财务方程在运转。

讲第五件事——Codex 从代码工具变成了"桌面 Agent"。

一个容易被 GPT-5.5 抢走注意力的事件——4 月 16 号的 Codex 大更新。这次更新里，Codex 从"云端代码 agent"切换成了"桌面 Agent"。

看这套新能力。电脑操控——Codex 有了自己的光标，可以点击、打字、操控 macOS 上任何 app。在后台跑不干扰用户。测试前端、操作没有 API 的工具、修 GUI-only bug，这些过去脚本很难触达的场景被打开了。内置浏览器——支持打开 localhost dev server 和本地文件页面。改代码、看效果、再改这个循环，第一次不用切出 IDE。记忆系统——跨会话保留上下文和用户偏好，不用每次重新说明。自动化调度——可以排定未来任务，agent 自动唤醒继续跑，支持跨天跨周。90 多个新插件——Atlassian、CircleCI、GitLab、Microsoft Suite 全都接入。iOS 上线——手机上能发起任务、查 diff、推 PR，锁屏显示任务进度。

这套产品动作方向很清楚——Codex 不再是"打字让我写代码"，是"我在后台帮你跑完一天的工作"。这跟 Claude Code 的定位产生了明显错开。Claude Code 是终端原生、直接在本地代码库上跑 shell 命令。Codex 是云原生、独立沙箱、异步并行。

XDA Developers 有个作者试了一周 Codex 然后又续费了 Claude Code。他的原话是——Claude Code 问问题、解释权衡、带你走选项的习惯，是真正有教育意义的体验。这是两种不同的 Agent 哲学。Codex 先动手边做边调整；Claude Code 先对齐再一次做对。前者适合批量、并行、探索性任务；后者适合高精度、一次改对的关键提交。

最后还有一个被掩盖的细节——三连降智。

就在 GPT-5.5 发布当天，Anthropic 主动披露过去两个月 Claude Code 出过三个 bug 导致变笨。

第一个 bug——3 月 4 号到 4 月 7 号，默认推理从 high 调为 medium，换延迟换能力。官方措辞是"这是错误的权衡"。第二个 bug——3 月 26 号到 4 月 10 号，缓存逻辑写错了，每次对话循环都清缓存，Claude 变得健忘又重复。第三个 bug——4 月 16 号到 4 月 20 号，系统 prompt 加了字数限制，内部测试发现 Opus 4.6 和 4.7 都下降 3%。

三个 bug 发生在不同时间，但选在 GPT-5.5 发布同一天集中披露——这是危机公关的时间管控。更实质的信号是，三个 bug 叠加期正好是 Opus 4.7 发布前的备战期。这段时间很多开发者在用的 Claude Code，实际上是限频的、带隐性降级的版本。社区对 Anthropic 这两个月的印象，很大程度来自这些 bug 覆盖下的体验。

还有一处沉默值得留意——Dario Amodei 在 GPT-5.5 发布后没有发表公开技术回应。4 月他主要出现在和白宫的政策谈判新闻里。Anthropic 这一轮的技术叙事没有 CEO 级别的声音站台。对比 Greg Brockman、Sam Altman 在 X 上持续刷存在感，这是一个 signal 强度的结构性差距。

所以最后总结三个关键词。

第一个词——分叉领先。不是全面碾压，而是在自己选的赛道上刷新高。GPT-5.5 拿下 Agent 赛道，Claude Opus 4.7 守住代码工程。同一时代，不同强项。企业团队做工具选型，要按任务路由，不要按 benchmark 总分选。

第二个词——20 美元战线。模型竞争的主战场从 benchmark 挪到了月度订阅档位。每月 20 美元能用上什么 Agent，直接决定百万开发者的日常选择。定价本身成了产品。

第三个词——Agent 消费。过去按对话次数算，现在按后台 agent 跑了多少小时算。一个重度用户消耗等于 100 个普通用户。订阅架构正在被重新设计，这件事会继续发酵。

这期就到这儿。我们下期见。
