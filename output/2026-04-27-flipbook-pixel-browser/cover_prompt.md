# 封面图 Prompt（给 Codex / GPT Image 2）

## 任务
为一篇中文深度拆解文章生成一张全文压缩信息图作为封面，放在标题之后、正文之前。要求字密、信息浓缩、可读性强、视觉沉稳。

## 文章核心
**主标题**：flipbook.page —— 当浏览器不再渲染 HTML，每个像素都是模型画出来的

**核心命题**：flipbook.page 把整个浏览器的渲染层换成了视频扩散模型 —— 屏幕上每一个像素都是 AI 实时生成的，没有 HTML、没有 DOM、没有代码。这不是又一个 AI 演示工具，而是"生成式 UI 作为计算原语"的赌注。

## 必须出现在图里的核心信息

1. **主论点（最大字号）**："生成式 UI 作为计算原语 / 屏幕的每一个像素都是模型画出来的"
2. **三种品类对比**（横向矩阵）：
   - Gamma / Tome：AI 填模板，HTML 不动
   - Websim / v0：AI 写 HTML，浏览器照常渲染
   - flipbook.page：AI 直接出像素流，跳过 HTML
3. **技术栈**：LTX Studio DiT 视频模型 + Modal Labs serverless GPU + WebSocket 1080p/24fps
4. **像素即一切的代价**（4 项）：
   - 没有可选文字（Cmd+C 失效）
   - 没有 SEO（爬虫看到空 canvas）
   - 没有可访问性（屏幕阅读器空白）
   - 幻觉极隐蔽（视觉自信掩盖错误）
5. **三层时间判断**：
   - 1–2 年：玩具，吃低 IA 信息浏览
   - 3–5 年：维基/科普类被蚕食
   - 5+ 年：HTML 不死但"应用 UI 必须由人写代码"这条公理松动
6. **盲区永久安全区**：金融、医疗、法律、政府文书 —— 需要文字证据的场景结构性免疫
7. **创始人金句**："Even ones you'd assume need structured UIs like coding." — Zain Shah

- **字体**：中文 PingFang SC，英文 Inter（或类似无衬线）

- **要求**：字可以多，信息密度优先，留白克制；不出现 emoji；不出现卡通插画
- **必须中文为主**，关键英文术语保留（HTML, DOM, CSS, LTX DiT, WebSocket, SEO）
