## 标题

地图厂商开始为 AI 备货了

## 正文

打开一家中文地图厂商的开放平台首页，最显眼的位置不再是"API 文档"，而是一个叫 Skill 专区的入口。
13 个月里它把交付物形态改了三次：API+SDK → MCP Server → Skill，每次改的不是底层能力，是包装层。
这是在"卖 API 调用次数"，还是在"为 Agent 备货"？
这组图把账单走向、协议站队、产品取舍，和三个被"零门槛"压住的盲区一次讲清楚了。
当能力变成 Agent 的常驻技能，计费就从单次调用迁移到月活订阅，地图厂商退到水电级基础设施。
你觉得地图这门生意会被 Agent 重新洗牌吗？评论区聊聊你的判断。
