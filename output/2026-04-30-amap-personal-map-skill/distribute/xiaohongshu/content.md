## 标题

高德把地图做成了 Skill

## 正文

2026 年 4 月 26 日，高德地图开放平台官方在小红书发布"个人地图 Skill"：用户用自然语言说需求就能生成专属地图（来源笔记 xiaohongshu.com/discovery/item/69eb324c…）。打开高德开放平台首页，最显眼的位置已经不是"API 文档"和"SDK 下载"，而是一个叫 Skill 专区的入口。

为什么值得看：距离 Anthropic 公开 Skills 协议规范（一个 SKILL.md 加一个 references/ 目录的极简约定）不到一个季度，高德的"个人地图 Skill"连目录结构都同构——github.com/AMap-Web/amap-skills 根目录是 SKILL.md，下挂 13 个 references/*.md。13 个月里高德对开发者交付物的形态改了三次：先是 API+SDK 文档，2025 年 5 月升级 MCP Server，2026 年 3 月起做 Skill 专区。每次改的不是底层能力，是包装层。

只看那条视频笔记，这是面向 C 端的零代码功能宣发；放回 13 个月的产品节奏里看，这是一家地图厂商正式从"卖 API 调用次数"切换到"为 Agent 备货"的拐点信号。

对从业者意味着什么：基础设施厂商正在主动适配 Agent 的消费习惯——谁先把能力包装成 Agent 能直接吃的格式，谁就抢到 Agent 时代的默认调用位。判断一家基建公司有没有踩对节奏，看它的交付物形态变了几次、朝哪个方向变。
