---
title: 9个接口背后藏着24万欧元
---

## 一次发九个有讲究

四月二十八号，Claude 官方三十秒抛出九个创作工具接口:Adobe、Ableton、Splice、Affinity、Autodesk Fusion、Blender、SketchUp、Resolume Arena 与 Wire。为什么九个一起发?分九次发是九次"功能更新"叙事,一次性九个是一次"生态宣言"叙事。前者卖功能,后者定义类目。官方措辞很克制:"让 Claude 与创意专业人士依赖的软件协同工作"。翻成大白话:Claude 不替代专业工具,它当编排器,专业工具当执行器。

## 名单里谁缺席

读完九件套,最快冒出的反问是:Figma 呢?这两年它是设计师默认工具,按理排第一梯队,却很可能永远不会出现。原因不复杂:Figma 自己在做接口的中枢,早已上线服务器给客户端调用。它不是不接,是不愿做被一键开关的"端"。每个被接入的工具都在做一次自我定位——我是端,还是枢纽?这一波九件套全部站在了"我是端"那一边,因为它们靠工具内深度使用赚钱,被引流不威胁主收入。

## 24万欧元等于四个工程师

开源基金会的最高公开档位门槛是每年24万欧元,这次的捐赠正好按这个数填。CEO 把用途讲得很直白:用于核心开发,特别是 Python API 的维护改进。重点来了——这正是 Claude 的 Blender 接口调用的同一套接口。一边用它的 API 卖接口,一边给 API 维护团队发工资。24万欧元在那一侧覆盖约四名全职工程师年薪,在巨头这侧不过零头。花零头给生态最薄弱一环续命,反过来保证自己产品能持续工作。

## 这不是AI接管

CEO 很懂如何处理社区情绪。他在公告里直接说:"这是帮助 Blender 这个软件本身,不是一次 AI 接管。"并强调赞助"不附带任何条件",与此前其他大厂的赞助同性质,不代表 Blender 认可该公司的产品或使命。这段话同时安抚两群人:担心 AI 公司渗透开源的艺术家,和担心 Blender 偏向 AI 路线的传统用户。一笔捐款,买的是技术保险,卖的是社区信任。

## 这件事对手没做

横向看其他几家大厂都在卷模型、搭工具接口,但截至四月底,没有一家出现在这个开源基金会的捐赠人列表里。过去两年这份名单里有 Meta、AMD、NVIDIA、微软、Intel、Epic Games,生成式 AI 阵营一片空白。为什么要做对手没做的事?第一层是 PR,直接买一份"和创作者站在一起"的姿态;第二层是产品,抽象的安全叙事需要具体物证;第三层是技术防御,Blender 是九件套里唯一开源、API 最深的一个,出问题接口就大面积失灵。

## 给实践者的一记潜台词

如果你在评估接 MCP 协议的时机,这次九件套是最强的生态信号:它愿意把接口当主线产品推,专业软件商愿意做被调用方,九个名字坐实了 MCP 不是协议层小众实验。如果你的产品要让用户"用自然语言驱动专业工具",范式可照抄:先把"AI 是编排器,专业工具是执行器"作默认架构。最后那24万欧元是一记潜台词——做生态的人要愿意给生态垫钱。业务踩在开源底盘上,预算里留一笔反哺的钱不是花费,是保险。
