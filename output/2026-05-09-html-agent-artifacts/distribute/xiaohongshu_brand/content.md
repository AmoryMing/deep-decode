## 标题

AI 不爱写 Markdown 了

## 正文

一个 Claude Code 团队成员说漏了嘴:他越来越不想让 Claude 输出 Markdown,而是直接生成 HTML 文件。
Markdown 当年凭"好 diff、人愿意手改"胜出,可一旦修改也交给 Agent,这条护城河就少了一半。
那 HTML 真要替代 Markdown 吗?恰恰相反——原文自己承认 HTML 多花 2-4 倍时间、diff 噪声大、更难 review。
这组图讲清楚了一件事:Markdown 没死,只是退回源文件层;HTML 抢走的是"给人看的 Agent 输出界面",做工作台,不做档案柜。
你在 Agent 工作流里更想要哪一层?评论区聊聊你的判断。
